# Sluby landing page

The public page for Sluby. A static site built with Vite and React.

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # writes the static site to dist/
npm run preview  # serves dist/ locally
```

`dist/` is plain static files. Serve it from any web server or static host; there is no server-side code and no environment variables.
